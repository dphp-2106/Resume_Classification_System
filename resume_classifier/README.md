# SAMATRIX ResumeForge 2026
## End-to-End Resume Classification System

> **SAMATRIX Hackathon 2026** — NLP/ML Track

---

## 🚀 Problem Statement

Build an end-to-end Resume Classification system that takes raw resume text and predicts the correct professional category from 24 possible classes.

## 🔬 Methodology

### 1. EDA
- Class distribution (bar + donut chart)
- Text length analysis (histogram + boxplot per category)
- Top-20 word frequency
- WordCloud (all categories + 8 individual category clouds)
- Bigram and trigram analysis
- TF-IDF category heatmap (top discriminating terms)
- Noise analysis (HTML, URLs, emails, very short docs)

### 2. Preprocessing Pipeline (`preprocessing_utils.py`)
The same function is called at training AND inference time:
1. HTML tag removal
2. URL → `url_token`
3. Email → `email_token`
4. Phone → `phone_token`
5. C++→cpp, .NET→dotnet, Node.js→nodejs normalization
6. Lowercase
7. Non-ASCII removal
8. Special character removal
9. Whitespace normalization
10. Tokenize + stopword removal + lemmatization
11. **Technical tokens preserved** (Python, SQL, AWS, TensorFlow, etc.)

### 3. Feature Engineering
- **TF-IDF Unigram** (max 15,000 features, sublinear_tf=True)
- **TF-IDF Bigram** (max 20,000 features, sublinear_tf=True)
- **Word2Vec** (200-dim, Skip-gram, window=10, neg sampling=10, trained on train only)
- **Document vectors** = mean pooling of Word2Vec word vectors

### 4. Models Trained
| Model | Features | Notes |
|-------|----------|-------|
| Logistic Regression | TF-IDF (uni + bi) | C=5.0, multinomial |
| LinearSVC | TF-IDF bigram | C=1.0 |
| Multinomial NB | TF-IDF unigram | alpha=0.1 |
| XGBoost | TF-IDF bigram | 300 trees |
| LightGBM | TF-IDF bigram | balanced |
| W2V + MLP | Word2Vec | 512→256→128 |
| W2V + LightGBM | Word2Vec | 400 trees |
| **Ensemble** | TF-IDF + W2V | 0.6 classical + 0.4 DL |

### 5. Train / Val / Test Split
- **70% train / 15% val / 15% test** — stratified
- TF-IDF fitted **only on training data**
- Word2Vec trained **only on training corpus**
- Test set kept **untouched** until final comparison

### 6. Evaluation Metrics
- Accuracy
- Precision (macro + weighted)
- Recall (macro + weighted)
- **Macro-F1** (primary metric — equal weight across all classes)
- Weighted-F1
- Confusion matrix (normalized)
- Per-class breakdown

### 7. Error Analysis
- Full error table with true label, predicted label, confidence, text preview
- Top confused category pairs
- Error rate per class chart
- Confidence distribution: correct vs incorrect
- Root cause investigation

---

## 🎯 Key Findings

1. **Best classical model:** LightGBM (TF-IDF bigram) — highest Macro-F1
2. **Hardest classes:** BPO, AUTOMOBILE, AGRICULTURE (small samples)
3. **Most confused pairs:** FINANCE↔BANKING, HR↔BUSINESS-DEVELOPMENT
4. **Word2Vec** captures semantic relationships missed by TF-IDF
5. **Ensemble** outperforms individual models on held-out test set
